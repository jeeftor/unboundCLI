# Security Policy

## Supported Versions

caddy-dns-sync is under active development. Only the **latest release** receives
security fixes. Please update to the most recent tagged release before reporting
a vulnerability.

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |
| < latest| :x:                |

## Reporting a Vulnerability

**Do NOT open a public GitHub issue for security vulnerabilities.**

If you believe you have found a security vulnerability in caddy-dns-sync, please
report it responsibly using one of the following channels:

1. **GitHub Security Advisories** — use the
   [Private Vulnerability Reporting](https://github.com/jeeftor/unboundCLI/security/advisories/new)
   feature on the repository. This keeps the report private to the maintainers.
2. **Email** — contact the maintainer directly. Include a description of the
   issue, steps to reproduce, and the potential impact.

Please do not disclose the vulnerability publicly until a fix has been released.

## Response Timeline

- **Acknowledgment**: within **72 hours** of the initial report.
- **Assessment**: a preliminary assessment of validity and severity within
  **7 days**.
- **Fix**: a patch or mitigation is targeted for the next release. The reporter
  will be kept informed of progress and coordinated on disclosure timing.

These timelines are best-effort commitments for a community-maintained project.

## Supply-Chain Artifacts

Each release of caddy-dns-sync publishes the following supply-chain security
artifacts, which you can use to verify the integrity and provenance of the
binaries you download:

- **SBOM** (Software Bill of Materials) in SPDX format, generated by
  GoReleaser and attached to each release.
- **SLSA L3 provenance**, produced via the SLSA GitHub generator, attesting to
  the build's integrity and the source it was built from.
- **Cosign signatures** for release artifacts, allowing verification with
  `cosign verify`.

Please verify these artifacts when consuming caddy-dns-sync in production or
sensitive environments.
